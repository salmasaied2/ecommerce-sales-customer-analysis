# 🛒 E-Commerce Sales & Customer Analytics Dashboard

An end-to-end data analytics project showcasing sales performance tracking and customer segmentation (RFM Analysis) using Python and Power BI.

## 📊 Project Overview
This project analyzes online retail data to uncover key business insights, track financial Key Performance Indicators (KPIs), and segment customers into behavioral groups to optimize marketing and sales strategies.

## 🛠️ Tech Stack & Tools
- **Python (Google Colab):** Data Cleaning, Exploratory Data Analysis (EDA), and RFM Customer Segmentation (Pandas, Seaborn).
- **Power BI Desktop:** Data Modeling, DAX Measures, and Interactive Dashboard Design.

## 📂 Project Structure
- `notebook/` : Contains the Google Colab / Python script for data processing and EDA.
- `data/` : Cleaned datasets (`cleaned_online_retail_data.csv` & `customer_rfm_segments.csv`).
- `dashboard/` : Screenshot of the final Power BI interactive dashboard.

## 🚀 Key Insights & Features
- **KPI Cards:** Track Total Revenue, Total Orders, Total Unique Customers, and Average Order Value (AOV) dynamically.
- **Trend Analysis:** Visualizes revenue growth and trends over time using interactive line charts.
- **Product Performance:** Identifies top-performing products driving the highest sales.
- **Customer Segmentation (RFM):** Categorizes customers to distinguish high-value VIPs from regular buyers.
